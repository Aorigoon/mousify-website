# Mousify website

Landing page for Mousify — your phone is your PC's touchpad (Linux PC + Android phone, Wi-Fi/LAN + Cloud mode).

- Next.js 15 + Tailwind CSS 4 + TypeScript
- Live site: deployed via OpenNext on Cloudflare Workers (see deploy notes in repo)
- App repo: https://github.com/Aorigoon/mouse

## Develop

```bash
npm install
npm run dev
```
